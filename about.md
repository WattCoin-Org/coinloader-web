# About CoinLoader.com

CoinLoader.com is a storefront for crypto, Solana and security agent templates for Grok Bot. It is operated by 3D-Composites. Its sister storefront for non-crypto agents is [BotAppStore.com](https://botappstore.com). The free Web & API Text Extractor can optionally use the WattCoin (WATT) Agent Registry at [wattcoin.org](https://www.wattcoin.org); no token is needed to buy or run a paid template.

## What we sell

Each product is a single-file, deterministic Python 3.10+ command line tool plus a one-click Grok Bot skill bundle. The bots are read-only: they audit wallets, tokens, contracts, approvals, Bitcoin UTXOs, perpetuals positions and tax lots, and print findings with evidence. They never ask for private keys or seed phrases and never sign or broadcast transactions. One free bot, the Web & API Text Extractor, is available with a 100 WATT starter grant; the paid bots are one-time purchases from $19 to $49 with no subscription.

## How payment works

Prices are quoted in USD and settled on-chain in SOL at the live rate, with a 15-minute quote and an exact on-chain transfer check. You receive a one-time `wcl_...` license key that unlocks the bot and its runtime download.

## Refunds and support

Refunds are available within 15 days of purchase. When a refund is issued, the license is revoked. See the [privacy and refund policy](https://coinloader.com/privacy.html) and the [contact page](https://coinloader.com/contact.html) for how to reach us.
